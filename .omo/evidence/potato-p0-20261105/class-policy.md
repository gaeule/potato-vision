# P0 목표·클래스·라벨 규칙

날짜: 2026-11-05. 두 과제를 별도로 관리한다. 이번 범위는 P0 데이터/검증/참조/평가 정리이며 새 결함 모델 학습이나 배포 승인이 아니다.

## 사용자 결정 원문

1. 목표 클래스: `두 과제를 별도로 진행`
2. 결함 출력: `결함 종류별 분류`
3. 결함 종류: `표면 결함 4종 (Recommended)` — 질문의 선택지 설명: 정상과 함께 녹변·발아·부패·상처를 구분하고 외관상 확정 불가는 판단 불가.
4. 복수 결함: `모든 결함 기록 (Recommended)` — 한 감자에서 여러 결함을 동시에 기록.

## 과제 A: 감자·돌 객체 탐지

기존 `retraining_data/outputs/dataset_v2/data.yaml`의 `0: potato`, `1: stone`을 유지한다. 단위는 이미지/프레임 안의 물체 박스다. 이미지·라벨·기존 모델은 수정하지 않는다.

확인되는 개체마다 보이는 범위를 기록한다. 가림 뒤 형태를 상상하지 않고, 재질/개체가 불명확하면 별도 보류한다. 알려진 불확실 물체를 미라벨 배경으로 학습하지 않는다. 감자 몸통과 싹은 구분하며, 공개 라벨의 몸통 경계 계약은 기존 재설계 참조 계획을 따른다. 기존 현장 라벨의 기준 차이는 보고하고 몰래 수정하지 않는다.

과거 지표의 감자/돌 의미와 평가 조건을 유지한다. 과제 B 결함 성능으로 재사용하지 않는다.

## 과제 B: 감자 개체별 결함 종류 분류

라벨 단위는 전체 장면이 아닌 감자 개체다. 각 표본은 원본 세션/파일/프레임, 개체 ID와 식별 영역에 연결한다. 같은 장면의 다른 감자 결함을 해당 개체에 붙이지 않는다.

별도 네 필드: `greening`(녹변), `sprouting`(발아), `rot`(부패), `damage`(상처). 각 값은 `present`, `absent`, `unknown` 중 하나다. 과제 A의 클래스 숫자와 섞지 않는다.

복수 `present`를 허용한다. 녹변+발아는 두 항목 모두 present다. 이 기록을 대표 클래스 하나로 덮거나 단일 선택 분류로 변환하지 않는다.

`normal_visible=true`는 네 필드가 모두 absent이며 모두 판정 가능한 경우에만 도출한다. 하나라도 unknown이면 정상이 아니라 검수 보류다. 이는 보이는 면의 판정이며 가려진 면이나 내부 품질을 확정하는 주장이 아니다. 정상은 네 결함과 경쟁하는 독립적인 다섯 번째 단일 선택 클래스가 아니다.

### 초기 작업 정의 — 명시적 가정, 현장 기준이 생기면 새 버전으로 변경

- 녹변: 감자 표면의 식별 가능한 녹색 변색. 조명/그림자/색 왜곡과 구분하지 못하면 unknown.
- 발아: 식별 가능한 싹의 발생. 눈 자국이나 작은 돌출이 싹인지 불명확하면 unknown.
- 부패: 외관상 식별 가능한 부패성 변화. 흙·그림자·멍만으로 부패를 추측하지 않으며 애매하면 unknown. 영상 라벨을 실물 검사 결과로 표현하지 않는다.
- 상처: 식별 가능한 껍질 손상·균열·절단·노출 조직 등 외상. 자연 무늬나 부착물과 구분하지 못하면 unknown.
- assumed: 이 단계는 유무 기록이며 중증도·면적 등급이나 출하 합격 임계값은 정하지 않는다. 사용자 요청은 결함 종류이며 등급 규격은 제공되지 않았기 때문이다.
- assumed: 선명도·가림·색 상태가 판단을 막으면 항목별 unknown과 이유를 기록한다. unknown을 음성 정답으로 학습/평가하지 않는다.
- assumed: 부분 가림/작은 물체/흐림/흙 부착은 결함 종류 자체가 아니라 품질·문맥 속성으로 기록한다.

기록 필드: 원본 해시, 촬영 세션, 개체 ID/영역 출처, 네 결함 값, normal_visible, unknown 이유, 가림/크기/배경 메타데이터, 작성자·재정자·확정 상태. AI 검수는 AI provenance로 남기고 human_reviewed로 승격하지 않는다.

## 독립 평가 규칙

분할 단위는 촬영 세션/원본 개체·증강 가족이다. 같은 원본의 복사·리사이즈·증강·인접 프레임만으로 새 세션이라고 하지 않는다.

과제 A는 클래스별 검출 AP/P/R/F1, 배경 포함 혼동행렬, 박스/개체 오류를 보고한다.

과제 B는 다중라벨 계약을 별도로 지원하는 모델·정답이 확보된 뒤 결함별 AP/P/R/F1와 항목별 TP/FP/FN/TN을 보고한다. 다중라벨을 단일 multiclass 혼동행렬 하나로 오해하지 않는다. 현재 결함 모델이 없으면 지표는 `NOT_TRAINED/NOT_EVALUATED`이고 0이나 과제 A 수치로 채우지 않는다. 정상·unknown 수와 결함별 판정 가능한 분모를 별도 공개한다.

새 촬영 자료와 정답이 확보되지 않으면 신규 세션 평가 목표는 미완료다. 기존 사진 성능표는 과거 자료 재현으로만 표시한다.

## 공개 라벨 참조 관문과의 관계

참조 관문은 과제 A의 감자 몸통 경계에 관한 작업이다. 원래375개·필수338개·고정 실패36개·동일32개 표본과 STOP 조건을 유지한다. 사용자 P0 실행 요청은 이 참조 단계의 수행을 승인한 것이며 CPU 윤곽 후보 생성·전체375 평가·100장 시범·결함 모델 학습을 자동 승인하지 않는다.
