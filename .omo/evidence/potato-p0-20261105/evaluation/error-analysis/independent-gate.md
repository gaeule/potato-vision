## 변경 범위와 정리

작성 대상은 independent-gate.md와 verified-strata.json 두 파일뿐이다. 기존 사이드카 100개 파일(렌더 88개 포함)의 시작 시 바이트 해시를 보관했고, 주석에 기록된 기존 근거 10개 보존 해시도 모두 일치했다. 새로운 렌더·임시 파일·백그라운드 프로세스·설치·모델/라벨 수정·하위 에이전트 실행은 없다. 보존해야 하는 기존 렌더나 수집기 파일을 정리 명목으로 삭제하지 않았다. 검증 스크립트 파일을 추가하거나 수집기/최종화기를 재실행하지 않고 상주 커널에서 읽기 전용으로 재계산했다.

작성 후 기존 100개 파일의 해시가 모두 유지되고 추가 파일은 지정한 두 개뿐임을 확인했다(총 102개). 실제 출력 JSON을 Python으로 재파싱하여 39개 ID·좌표·주석 보존, 모든 계층 집계, 보고서 표와의 일치, 38개 프레임과 58회 배경 소속을 검증했다. 모두 PASS이다. JSON LSP 진단은 기존 Biome 실행 파일이 없어 수행하지 못했다. 설치 금지 범위를 지켰으며 JSON 파싱과 데이터 정합성 검사는 별도로 통과했다.
