## 독립 참조와 후보 정책

### 원본 참조

독립 작성자2명이 원본 전체 문맥과 불변 식별점을 보고 보이는 몸통 polygon/multipolygon, 몸통/싹 설명, 식별 가능성 S/F/U를 작성한다. 가림 때문에 보이는 부분이 분리될 수 있으며 숨은 몸통은 상상하지 않는다. 참조 좌표를 생산 후보로 복사하지 않는다.

한 명이라도 불확실하거나 개체·몸통 돌출부·부속물·외곽에 이견이 있으면 독립 재정1회만 허용한다. 재정자는 원본과 두 기록으로 기존 주석 하나를 선택하거나 U로 판정하며, 제3의 polygon을 새로 그리지 않는다. 재정 후에도 몸통 해석이 명확하지 않으면 U다. 원본 픽셀을 바꾸지 않고 rasterize하며 작성자·재정자 출처와 AI 참조임을 명시한다. 좁은 몸통 누락을 허용하는 polygon 겹침 허용률로 의미 불일치를 덮지 않는다.

참조 작성자에게는 원본·대상 ID·원래 식별점만 제공한다. 보충점·사용자50개 판정·캐시 마스크·기존 판정·참조 관문 산출물은 제공하지 않는다. 보이는 몸통 경계를 판정할 뿐 고정된 개체/상태 원장을 고치지 않는다.

생성기는 참조 파일에 접근하지 못한다. 참조와 고정된 유효/보충 점 제약의 충돌은 비성공이다. 점을 바꾸거나 몸통을 깎아 맞추지 않는다. null7에는 점·polygon을 만들지 않는다.

### 고정 후보 생성

적격 대상당 한 번 호출하며 신경망 호출은0회다.

1. 원본 전체 프레임에 GrabCut 마스크를 초기화한다. 저장 generate raw는 probable foreground, 나머지 콘텐츠는 probable background로 둔다. 원래/보충 양성점은 probable 라벨을 hard foreground로, 확정된 콘텐츠 밖 막대는 hard background로 덮는다. 유효 전체/보충 음성점은 초기 라벨을 바꾸지 않고 독립 출력 제약으로 남긴다. 같은 픽셀이 필수 양성과 음성이면 `contradictory_labels`로 사전 실패한다. 범위 밖 점·전경/배경 표본 부족·해시 오류도 대체 처리 없이 실패다. 이미지 테두리나 옛 박스 밖을 일괄 배경으로 두지 않는다.
2. 매 대상의 GrabCut 호출 직전에 `setRNGSeed(20261102)`와 `setNumThreads(1)`를 실행한다. mask 초기화·내부 반복5회이며 seed·스레드·버전을 영수증에 기록한다. 배치 시작 때 한 번만 설정하지 않는다. 결과의8연결 전경 중 원래 양성점 성분을 택한다. 원래/필수 보충 양성점이 없으면 실패다. 다른 성분은 기록하며 전체 몸통이라고 슬쩍 합치지 않는다.
3. 후보는 최대3개다. 무절단 원본 결과, 목 폭3% 절단, 목 폭6% 절단. 의미 정답이 아닌 가설이다.
4. L은 base mask extent의 긴 변이다. 외곽 `CHAIN_APPROX_SIMPLE` contour의 convexity defect 최심점인 오목 정점 쌍을 열거한다. 길이0 또는 각 비율×L보다 긴 쌍은 제외하며 유클리드 길이는 반올림하지 않는다. 정점은 원본 정수 픽셀 좌표다. 두 끝점의1픽셀 `LINE_8` 중심선 픽셀 전체가 현재 전경이어야 한다. `cv2.line(thickness=3, lineType=LINE_8, shift=0)` 띠를 제거하고 원래 양성점을 포함한8연결 성분을 남긴다. 절단 띠 픽셀을 복원하지 않는다. 모든 양성점을 보존하고 띠 밖 제거 돌출부가 연결성분 하나여야 한다. 돌출부 픽셀 중심에서 유한 절단 선분까지의 최대 유클리드 거리가 목 길이의2배 이상이어야 유효하다.
5. 제거 돌출부 면적 내림차순, 정규화한 끝점 좌표 사전순으로 선택한다. 첫 유효 절단을 적용하고 다시 계산하며 변형당 최대8번이다. 두 폭 변형은 동일 base에서 각각 시작하며 L은 고정한다. 모든 절단 좌표·중간 해시를 보존한다. 유효 절단이 없으면 base와 동일하고, 동일한 최종 마스크는 출처를 남기고 중복 제거한다.
6. bbox는 실제 마스크 extent이며 원본 좌표, 우하단 exclusive다. 과거 가드에 맞춰 좌표를 바꾸지 않는다. 전경 성분에 유효/보충 음성점이 들어가면 `negative_in_component`로 무효다. 음성점 자리에 구멍을 만들어 통과시키지 않고 판별력 있는 출력 검사를 유지한다. originalP는 두 승인 예외로 false일 수 있으므로 별도로 보고한다.

contour 정점4개 미만·hull 정점3개 미만 또는 `convexityDefects`의 명시된 비단조 hull 오류에서는 해당 변형을 base 그대로 반환하고 `defects_unavailable`를 기록한다. 자동 대상 실패가 아닌 사전 정의된 무절단 분기다. 다른 오류까지 삼키거나 알고리즘을 교체하는 허가는 아니며, 그 밖의 라이브러리 오류는 STOP이다.1픽셀 spur와 L<100 fixture를 포함한다.

반올림·선 rasterize·동률 처리는 설치 버전과 합성 fixture로 고정하고 코드 해시를 동결한다. 실제 진단 이미지로 상수나 동률 규칙을 튜닝하지 않는다. 동결 전 구현 오류는 합성 fixture만 사용해 고칠 수 있지만 기대 동작을 약화해 테스트를 통과시키면 안 된다. 명세의 방법 자체가 fixture를 충족하지 못하면 STOP이며 다른 알고리즘으로 교체하지 않는다.
