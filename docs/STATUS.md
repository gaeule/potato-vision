## 완료된 기존 자료 평가

두 체크포인트를 val11/test12/external166에서 같은 조건으로 평가했다.
고유 성공6개, 최초 실패1개를 포함한 실제 `model.val` 호출7회이며
독립 최종 감사 PASS다. Git 기록 작업에서 모델을 다시 평가하거나 학습하지 않았다.

AP는 비율이다. 조건은 conf0.001, NMS IoU0.5, imgsz640, batch1, GPU0이다.
외부 돌은 정답이 없어 미평가다. 현재 모델의 내부 감자 AP는 높지만 돌
AP50:95와 외부 감자 AP는 낮다. 모든 지표가 개선됐다는 주장은 하지 않는다.
기존 conf0.45 운영점 P/R/F1은 AP 및 library best-F1 P/R과 분리한다.

오류39건(FP26/FN13)도 독립 검증했다. 배경 물체19, 정답 재검토 후보13,
작거나 잘린 대상3, 불명확4건이다. 후보13건은 정답 오류 확정이 아니며
라벨과 기존 FP/FN을 변경하지 않았다.

## 미완료 사항

- 원래 공개 라벨 계획은 **7/23** 완료다. SAM 보정은90% 기준을 통과하지
  못했고 원본 전용 참조 관문도 필수0014/T037의 경계 불확실로 중단됐다.
  375건 전체 합격,100장 시범,2,060장 수정본 완성을 주장하지 않는다.
- P0 목표는 **3/5** 완료다. 기존 자료의 평가표는 완성됐지만 신규 세션
  자료·출처·정답이 확인되지 않아 G004/G005는 차단 상태다.
- 새 사진은 별도 촬영 세션에서의 성능 검증에 필요하다. 기존 공개 사진의
  라벨 수정을 위해 새 사진이 필수인 것은 아니다.
- 과제 B는 녹변·발아·부패·손상 다중라벨 정책만 정의했다.
  모델과 결함별 성능은 NOT_TRAINED/NOT_EVALUATED다.

## 자료 복원

전체 데이터 의존 기능을 실행하려면 원본 영상·두 ZIP, baseline 데이터,
stone/retraining 데이터 및 검수 라벨, 각 체크포인트를 별도 보관소에서
복원해야 한다. 경로와 계약은 각 기능의 README 및 저장된 매니페스트
참조를 따른다. 이미 사용한 영상·external166을 신규 세션으로 분류하지 않는다.

`public_label_rework/outputs/protected_before.json`의 과거 보호 목록은
덮어쓰지 않았다. 저장소 도입 중 기존 보호 파일4,499개의 실제 SHA256을
비교해 변경·누락0개를 확인했다. 새 Git 메타데이터와 새 문서는 별도
승인된 추가 항목이다.
