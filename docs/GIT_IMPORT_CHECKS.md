# Git 도입 검사 기록

기준일: 2026-11-10. 현재 작업을 기능별10개 커밋으로 보관하기 위한 검사다.
모델 성능을 새로 측정하거나 기존 라벨을 수정한 작업이 아니다.

## 범위와 의존성

제품 Python 소스86개를 읽고 AST로 로컬 import 관계를 확인했다. 각 기능
묶음이 뒤 커밋의 모듈을 먼저 필요로 하지 않도록 순서를 정했다. 관련
스모크는 해당 구현과 함께 커밋하며, 분리하면 깨지는 학습·평가 코드는
같은 묶음으로 둔다. 보관하는 기존 AP 실행 도구3개도 별도로 구문 검사했다.

| 순서 | 기능 묶음 | 실행한 검사 |
|---:|---|---|
| 1 | 저장소 기본 설정·안내 | 원본/가중치/상태파일 ignore 확인, staged diff 검사 |
| 2 | 원본 프레임·기본 탐지 | Ruff, extract_frames/prepare_data/run_baseline 도움말, 선택 모듈 import·IoU 검사 |
| 3 | 감자·돌 파이프라인 | Ruff, `stone_experiment.smoke` |
| 4 | 재학습 데이터 | Ruff, `retraining_data.smoke` v1 및 `--profile v2` |
| 5 | 재학습·후처리 비교 | Ruff, `retraining_experiment.smoke`, 후처리 모듈 비실행 import |
| 6 | 영상 추적·계수 | Ruff, `tracking_experiment.smoke` |
| 7 | 공개 라벨 입출력·인벤토리 | Ruff, smoke_intake/smoke_labelio/smoke_inventory |
| 8 | SAM·후보·결정 적용 | Ruff, smoke_snap/smoke_snap_instances/smoke_decisions/smoke_apply_scope/smoke_detector |
| 9 | 검수 렌더·패키징 | Ruff, smoke_render/smoke_package/smoke_package_gate |
| 10 | 결과·근거 문서 | JSON 파싱, 선별 경로·크기·자격증명 패턴, 기존 AP 도구 구문·정적 검사 |

코드 검사는 기존 가상환경의 Python3.12와 Ruff를 사용했다.
모든 커밋에 대해 `git diff --cached --check`와 스테이징 파일 목록을 확인한다.
앞선9개 커밋의 diff 검사는 통과했다. 마지막 증거 보관 커밋에서는 기존
`evaluation/ap/independent-gate-v4.md`와 `evaluation/ap/verified-ap-v4.json`의
끝 빈 줄2건 때문에 diff 검사 종료2를 확인했다. `.omo/evidence/potato-p0-20261105/`
아래의 원본 증거 바이트를 보존하기 위해 공백을 제거하거나 검사를 숨기지 않았다.

중단 후 이어서 최종 문서 묶음을 확인했다. 미추적 상태였던
`tracking_experiment/review/video_review.md`도 기존 영상 검수 근거로 함께
보관한다. 연결된 원본 영상·검수 이미지·JSON은 기존 제외 범위를 유지한다.
이미 통과한 학습·평가·CPU 스모크는 이 문서 커밋을 위해 반복하지 않았다.

## 관측된 결과

- 데이터 v1은102장, v2는111장의 원본 해시와 출력 바이트가 일치했다.
- 공개 라벨은2,060/2,060개가 바이트 동일하게 왕복됐다.
- 추적의 방향·히스테리시스·가림 복귀·ID 만료·전역 할당·결정론과
  실제 CPU VFR 인코딩/디코딩 검사가 통과했다.
- SAM 검사는 CPU 기하·입력·해시·거부 경로만 실행했다.
  과거90% 품질 관문이 통과됐다는 뜻이 아니다.
- 결정 적용·패키징의 pilot/final2060 검사는 합성 픽스처다.
  실제 원본375건 재평가나2,060장 전체 수정·출하를 실행하지 않았다.
- 렌더22개 생성·자동 정리와 패키지 결정론·부적합 입력 거부가 통과했다.
- 기존 보호 대상4,499개 파일을 실제 SHA256으로 대조해 변경·누락0개였다.
  새 `.git/`과 저장소 문서는 승인된 추가 항목이며 과거 스냅샷은 그대로다.
- Python 소스의 고신뢰 토큰/개인키 패턴 검사에서 발견0개였다.
  이는 모든 비밀 정보의 부재를 수학적으로 보증하는 검사는 아니다.

제품 소스86개의 Ruff 검사와 CPU 스모크는 통과했다. 보관하는 AP 도구 중
`prepare_inputs.py:83`에는 기존 Ruff **SIM102 1건**(중첩 if)이 발견됐다.
AP 도구3개의 Python 구문은 유효하지만 이 추가 Ruff 명령은 종료1이다.
코드 해시가 과거 평가 프로토콜·독립 감사에 결합된 증거 파일이므로,
이번 Git 보관 작업에서 자동 수정하거나 규칙을 숨기지 않고 원문을 유지했다.

## 검사 명령을 바로잡은 사항

`scripts.select_checkpoint`와 `postprocess_review.sweep`에는 `--help` 처리기가
없는데 최초 점검에서 해당 인자를 전달했다. 기존 출력 디렉터리 거부로
각각 중단됐고, 코드상 모델 생성·추론 루프 전에 종료된 것을 확인했다.
실패를 성공으로 표시하거나 보호 조건을 완화하지 않았다.

이 두 스크립트에는 비실행 import 검사를 적용했다. checkpoint 선택의
순수 IoU 함수도 확인했다. 실제 학습·선택·후처리 sweep은 다시 실행하지
않았으며, 기존 출력이나 소스는 변경하지 않았다.

## 저장소와 외부 자료

원본 미디어·ZIP·가중치·캐시·대량 출력·실행 상태는 제외한다. 선별된
`.omo` 계획/근거는 정확한 파일 경로만 명시적으로 추가한다. 과거 실행 승인
파일, 활성 작업 상태, 계정 설정, 전체 세션 로그는 포함하지 않는다.

실제 원본과 검수 라벨을 요구하는 스모크는 자료가 준비된 현재
워크스페이스에서 검증했다. 새 clone만으로 해당 자료 의존 검사가 모두
통과한다고 주장하지 않는다. 원격 반영 여부는 Git 원격 상태와 최종
작업 보고를 기준으로 확인한다.
