# 기존 새 모델 영상 확인

원본과 `retraining_experiment/outputs/video/annotated.mp4`를 실제 디코딩하여
전체 10초 간격 장면, 33~37초 0.5초 간격 장면, 125~136초 1초 간격 장면을 확인했다.
저장된 비교 사진도 대조했다. 모든 프레임의 정답을 확정한 검수는 아니다.

- 감자는 롤러 위에서 화면 아래에서 위로 이동한다.
- 35초 상단에는 가까운 감자·손 주변 중복/오탐 박스가 남는다.
- 126초 화면 상단에 작은 돌 예측이 있으며 기존 평가에서 배경 오탐으로 기록됐다.
- 134초 화면 최상단 잘린 돌은 감자로 잡히지 않지만 검출 누락이 남는다.
- 136초 상단 경계에도 감자 예측이 남는다.
- 중앙부는 상단의 손과 잘린 물체를 피할 수 있어 집계선을 y=360으로 정했다.
  선의 유효 구간은 x=220~1000, 통과 방향은 위쪽이다.

기존 검출 조건 confidence=0.45, NMS IoU=0.5와 모델은 변경하지 않는다.
저장된 전 프레임 검출을 추적 입력으로 재사용한다.
중복·미검출이 있으므로 ID 및 누적 통과 수를 실제 고유 물체 정답이라고 주장하지 않는다.

수동 비교는 모델 박스 없는 원본에서 별도로 수행했다.
`manual_reference.json`은 추적 출력 확인 전에 기록한 AI 시각 집계이며,
사람이 검수한 정답이나 전체 영상 정답이 아니다.
