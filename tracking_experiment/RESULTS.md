# 감자 추적·기준선 누적 집계 결과

## 실제 실행 결과

기존 새 모델의 전체 영상 검출 결과를 재사용하여 감자 ID 추적과
기준선 통과 집계를 구현하고 전체 원본 영상에 실행했다.
모델 재학습이나 검출 임계값 변경은 하지 않았다.

- 전체 영상 자동 집계: **위쪽 통과 100건**
- 생성된 추적 ID: 131개. 이는 감자 개수와 다르며 오탐·추적 단절도 포함한다.
- 원본 2,224프레임, 147.875초, 1280×720을 모두 처리했다.
- 출력은 H.264 무음 MP4이며 모든 프레임의 PTS·time base·duration이 원본과 같다.
- 기존 원본·모델·검출·라벨·결과 파일 4,127개의 SHA-256을 대조했고 변경은 없었다.

**100건은 모델 기반 통과 집계이며, 실제 서로 다른 감자 100개를 확인한 값이 아니다.**
같은 감자를 다시 투입하면 다시 집계될 수 있다.

## 영상 확인과 집계 위치

기존 결과 영상을 실제 디코딩해 전체 흐름과 35·126·134초 전후를 확인했다.
상단의 손 주변 중복/오탐과 잘린 돌 누락이 남아 있었다.
감자가 아래에서 위로 움직이므로 상단을 피해 중앙 y=360에 집계선을 두었다.
유효 구간은 x=220~1000이다. 좌표는 원본 1280×720 기준이다.

동일 ID가 선 아래 y>=368에서 관측된 뒤 선을 위로 넘어 y<=352에 도달하면
한 번 집계한다. 짧은 누락은 0.5초까지 연결하며, 관측되지 않은 예측 박스만으로는
집계하지 않는다. 돌은 감자 추적·누적 집계에서 제외한다.

초록 박스의 `P번호`는 확인된 ID, 노란 `P번호?`는 아직 관측 횟수가 부족한 ID다.
화면 하단의 `ON SCREEN`은 현재 보이는 검출 수이고,
`UP LINE CUMULATIVE`는 기준선 위쪽 통과 누적 수다.

## 원본 영상 수동 비교

추적 결과를 보기 전에 모델 박스 없는 원본을 0.5초 간격으로 확인하여
세 구간의 비교용 통과 수를 기록했다. 이후 각 통과 시각과 위치도 대조했다.

| 구간 | 원본 시각 집계 | 자동 집계 | 수량 차이 |
|---|---:|---:|---:|
| 30초 이상~40초 미만 | 11 | 11 | 0 |
| 75초 이상~85초 미만 | 12 | 12 | 0 |
| 124초 이상~137초 미만 | 7 | 7 | 0 |
| 합계 | **30** | **30** | **0** |

이 33초 구간에서는 시각적으로 확인한 통과와 자동 사건이 일치했다.
비교에는 히스테리시스 확인 시각이 아닌 선 중심 통과 추정 시각을 사용했다.
이 참고값은 **AI가 원본을 시각 확인한 값이며 사람이 검수한 정답은 아니다.**
비교 구간의 숫자를 보고 추적 설정을 튜닝하지 않았다.

근거: `review/manual_reference.json`, `review/verification.json`,
`review/manual30.jpg`, `review/manual75.jpg`, `review/manual125.jpg`.

## 전체 영상 통과 대조 (2026-10-28 추가)

자동 결과를 보지 않는 별도 작업자가 원본 MP4만 0~148초 전 구간,
0.5초(애매한 곳은 더 촘촘히) 간격으로 확인하여 기준선 통과를 모두 기록했다.
모델 박스, 추적 출력, 기존 집계 파일은 열람하지 않았다.

| 항목 | 값 |
|---|---:|
| 원본 시각 기록: 감자 통과 사건 | 102 |
| 그중 같은 감자가 되돌아왔다 다시 통과한 사건 | 2 |
| 원본 시각 기록: 서로 다른 감자의 통과 | **100** |
| 원본 시각 기록: 돌 통과 (집계 대상 아님) | 10 |
| 자동 집계 | **100** |
| 1:1 대응 성공 | 100 |
| 누락 (같은 감자의 재통과 2건 제외 기준) | 0 |
| 중복·배경 오집계 | 0 |
| 돌을 감자로 집계 | 0 |

대응 기준은 원본 기록의 통과 시각 범위 ±0.35초, 통과 x좌표 차이 90px 이내의
1:1 매칭이다. 재통과를 포함한 통과 사건 102건 기준으로는 대응되지 않은 사건이 2건
(집계 차이 -2)이며, 아래에서 설명하듯 둘 다 같은 감자의 재통과다. 대응된 100쌍의 x 차이는 중앙값 2.5px, 최대 23.6px이다.
기준을 ±0.1초·50px로 좁히면 1건이 어긋나는데(20초대 P7),
실제 화면에서 같은 감자이며 원본 기록이 0.5초 간격 때문에 약 0.4초 늦게
기록된 것으로 확인했다(`review/t20.jpg`).

자동 집계와 대응되지 않은 원본 사건 2건(약 96.0초, 115.3초)은 원본 기록 자체가
"같은 감자의 재통과"로 표시한 경우다. 실제 추적 영상에서도 P94와 P112가
선을 넘은 뒤 잠시 선 근처로 내려왔다 다시 올라갔고, ID가 유지되어
각각 한 번만 집계됐다(`review/recross_95.6.jpg`, `review/recross_114.5.jpg`).
ID당 1회 집계 규칙이 의도대로 동작한 것으로, 오류가 아니다.

집계되지 않은 짧은 ID 31개도 확인했다. 대부분 화면 아래·위 끝에서 1~3프레임만
보인 검출이다. 선 아래에서 끊긴 4개(27.4·64.9·81.9·129.4초)는 흰색·파란색 돌이
1~2프레임 동안 감자로 오검출된 경우였고, 2회 관측 확인과 8px 여유 구간 때문에
집계되지 않았다(`review/case_*.jpg`).

**결론: 이 영상에서는 수정이 필요한 집계 오류(누락·중복·돌 집계)를 찾지 못했다.**
따라서 추적 코드와 설정을 바꾸지 않았고 결과 영상도 재생성하지 않았다.
확인된 오류 없이 이 기록에 맞춰 설정을 조정하면 같은 영상에 과적합될 뿐이다.
오류를 찾지 못했다는 뜻이며, 전체 영상에서 오류가 없음을 입증한 것은 아니다.
독립 검토자는 두 대조 결과를 별도 코드로 재계산했고 재통과 2건과 20초대 P7 판단을
원본 화면으로 확인해 승인했다. 일대일 대응은 탐욕적 매칭이지만,
엄격한 기준에서도 후보가 겹치는 자동 사건이 없어 바뀐 대응은 발견되지 않았다.
돌의 1프레임 오검출, 화면 상단 중복 박스 같은 검출 단계 문제는 남아 있지만
이번 집계 결과에는 영향을 주지 않았다.

이 원본 기록도 **AI 시각 기록이며 사람이 센 정답은 아니다.**
같은 영상 한 개에 대한 결과이므로 다른 촬영 조건에서의 정확도를 보증하지 않는다.

근거: `review/full_reference.json`, `review/full_comparison.json`,
`review/full_comparison_strict.json`.

## 검증

- 실제 전체 영상 실행 종료 코드 0.
- 별도 검증 코드가 100개 사건의 ID 유일성, 선 교차 좌표·시각,
  관측 프레임과의 대응 및 프레임별 누적 수를 확인했다.
- 원본과 완성 MP4를 각각 다시 디코딩해 2,224프레임 전체의 시각·길이를 대조했다.
- 완성 MP4의 시간별 장면, 연속 통과 장면과 마지막 누적 100 표시를 시각 확인했다.
- CPU smoke: 역방향, 재통과, 히스테리시스, 선 끝점, 누락·만료,
  ID 할당, 입력 순서, 확인 횟수, 캐시 거부, 실제 CLI·인코딩 회귀 검사 통과.
- Ruff lint·format 통과.
- Basedpyright: 오류 0개, 외부 의존성 타입 경고 30개로 종료 코드 1.
  경고를 억제하지 않았고 깨끗한 타입 검사 통과로 취급하지 않는다.
- LSP 서버는 없어 기존 환경의 타입 검사 CLI를 사용했다.
- 독립 코드 검토 승인: 차단할 기능 결함 없음. 출력에 기록된 코드 해시도 일치했다.
- 별도 읽기 전용 동작 검사 40건 통과: 선 위에서의 반전·정지,
  끝점 직전/직후, 돌 검출이 끼어드는 누락, 0.5초 경계,
  재통과, 잘못된 CLI 값 등을 추가 확인했다.

## 남은 한계

가림·인접 감자·빠른 움직임·검출 중복·누락 때문에 ID 단절이나 교환이 가능하다.
기준선 통과 집계가 영상 전체의 실제 고유 개수와 동일하다고 보장하지 않는다.
기존 35초 상단 중복 박스 등 검출 문제는 그대로이며 추적이 검출 자체를 고치지는 않는다.
별도 촬영 영상이나 사람 검수 정답을 이용한 검증은 하지 않았다.
2026-10-28 사용자 확인 결과 현재 다른 촬영 영상이 없다. ZIP의 사진 166장은
연속 영상이 아니어서 추적·통과 집계 검증에 쓸 수 없다. 재검증에는 다른 날짜나
다른 카메라로 찍은 감자 컨베이어 MP4가 필요하며, 사람이 센 통과 수가 함께 있으면
정확도를 정답 기준으로 평가할 수 있다.
실제 mm 크기 측정과 흙 별도 구분은 이번 작업에 포함하지 않았다.
