# NMS 중복 비교와 추가 라벨 검수 자료

## 결과

**판정 점수는 0.45로 고정하고 NMS IoU만 비교했습니다.**
기존 박스를 사후 필터링한 것이 아니라 각 후보로 모델의 NMS를 실제 재실행했습니다.
모델은 기존 감자·돌 `selected.pt`이며 재학습하지 않았습니다.

| NMS IoU | 검증 macro F1 | 시험 macro F1 | 70초 돌 박스 | 78초 감자 정탐 |
|---|---:|---:|---:|---:|
| 0.3 | 0.9503 | 0.9199 | 1 | 11/11 |
| 0.4 | 0.9503 | 0.9199 | 1 | 11/11 |
| **0.5** | **0.9503** | **0.9199** | **1** | **11/11** |

검증 11장에서는 모든 후보의 성능이 같았습니다.
사전에 정한 동점 규칙에 따라 중간 후보 0.5를 임시 후보로 골랐습니다.
**0.5가 유일한 최적값이라고 입증한 것은 아닙니다.**
후보 선택은 검증 지표만으로 끝내고, 이후 시험·학습 진단 장면을 확인했습니다.

70초의 같은 돌에 대한 중복 박스는 0.3~0.6에서 제거됐습니다.
확인한 인접 감자 장면 20·78·80초에서는 추가 감자 누락이 없었습니다.
80초의 기존 배경 오탐 1건과 134초의 돌→감자 오분류는 그대로입니다.
작은 표본의 확인 결과이며 모든 밀집 장면에 대한 보장은 아닙니다.

### 비교 자료

- `outputs/nms/comparison_70_78_134.jpg`: 중복 제거, 밀집 감자, 남은 오분류 비교
- `outputs/nms/metrics.csv`: 후보별 두 클래스 TP/FP/FN·정밀도·재현율
- `outputs/nms/selection.json`: 검증 전용 선택 규칙과 동률 후보
- `outputs/nms/summary.json`: 전체 집계

기존 영상과 기존 실행 설정의 NMS 0.7은 변경하지 않았습니다.
NMS 0.5는 이번 비교와 검수용 초안 생성에만 사용했습니다.

## 추가 검수 묶음

**공유용 파일:** `outputs/potato_stone_review_pack.zip`

- 이미지 50장 + 같은 이름의 X-AnyLabeling 형식 JSON 50개
- 자동 제안 박스: 감자 270개, 돌 30개
- 원본 시점: 1.0~83.5417초, 전부 기존 학습 구간 안
- 기존 63장과 프레임 중복·정확한 픽셀 중복 없음
- 모든 파일은 `checked=false`, 검수 목록은 `pending`
- 초안 생성 조건: confidence 0.25, NMS IoU 0.5

초안 생성은 사람이 누락을 찾아 수정하도록 비교 실험보다 낮은 confidence를 사용했습니다.
높은 점수나 이미 그려진 박스가 정답이라는 뜻은 아닙니다.
초안은 기존 학습 데이터에 편입하지 않았으며 재학습도 하지 않았습니다.

압축을 풀면 `review_pack/data`에 PNG·JSON이 같이 있습니다.
검수자는 `review_pack/README.md`의 안내를 따라 박스를 수정하고
`review.csv`에 완료 여부와 불확실한 사례를 기록하면 됩니다.
실제 돌인지 흙덩어리인지 애매한 물체는 현장 확인이 필요합니다.

`outputs/review_pack_spotcheck.jpg`는 대표 장면 8개의 자동 초안 미리보기입니다.
제작 과정에서 이 미리보기를 확인했지만, 50장 전체의 사람 검수를 대신하지 않습니다.

## 실행

작업 폴더 루트에서 다음 환경을 사용했습니다.

```sh
PY=/home/sc/.cache/potato-baseline/.venv/bin/python
OMP_NUM_THREADS=8 OPENBLAS_NUM_THREADS=8 "$PY" -B -m postprocess_review.sweep
OMP_NUM_THREADS=8 OPENBLAS_NUM_THREADS=8 "$PY" -B -m postprocess_review.pack
```

현재는 실행 결과가 이미 있으므로 같은 출력 폴더에 다시 쓰는 동작을 거부합니다.
재현할 때에는 기존 `outputs`를 별도 이름으로 보존한 뒤 실행하세요.
비교 조건과 추출 시점은 `protocol.json`에 고정했습니다.

## 검증과 한계

- NMS 0.7의 검증·시험 결과가 기존 결과와 정확히 일치했습니다.
- 새 50장을 원본에서 다시 디코딩해 픽셀·PTS·첫 요청 시점 대응을 확인했습니다.
- PNG·JSON 짝, 이미지 크기, 박스 좌표, 클래스, 미검수 상태를 전부 검사했습니다.
- ZIP 153개 항목의 CRC와 파일 목록을 확인했습니다.
- 기존 파일 2,220개의 SHA256이 그대로입니다.
- Ruff는 통과했습니다. 타입 진단은 오류 0개, 엄격 경고 38개로 종료 코드 1이며,
  경고를 끄거나 타입 검사가 통과했다고 표시하지 않았습니다.
- JSON 기본 필드는 X-AnyLabeling v4.2.0의 공식 스키마와 대조했습니다.
  이 환경에서 실제 데스크톱 GUI로 여는 동작은 확인하지 않았습니다.
- 같은 영상의 추가 시점이므로 새로운 촬영 조건을 확보한 것은 아닙니다.
  새로운 촬영 세션과 사람의 정답 검수가 여전히 필요합니다.

전체 검증 기록은 `outputs/verification.json`에 있습니다.
