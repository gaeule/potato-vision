# 감자·돌 추가 라벨 검수 묶음

## 아직 정답 데이터가 아닙니다

이 묶음은 원본 영상의 학습 구간 0~84초 안에서 추가로 추출한 50장입니다.
기존 학습·검증·시험 이미지와 같은 프레임은 제외했습니다.
같은 영상의 비슷한 장면이므로 새로운 촬영 조건이나 독립된 물체 50개를 뜻하지는 않습니다.

자동 모델이 제안한 박스이며 모든 JSON의 `checked`는 `false`입니다.
빈 라벨도 실제 물체가 없다는 뜻은 아닙니다.
이 파일들은 기존 학습 데이터에 자동으로 편입되지 않습니다.

## X-AnyLabeling에서 확인하기

1. ZIP을 사용할 경우 먼저 압축을 풀어 주세요.
2. X-AnyLabeling에서 `review_pack/data` 폴더를 이미지 폴더로 여세요.
3. PNG와 같은 이름의 JSON이 같은 폴더에 있습니다.
4. 각 이미지의 감자(`potato`)와 돌(`stone`)을 모두 확인하세요.
5. 누락된 객체는 추가하고, 장갑·설비·잘못된 종류·중복 박스는 수정하거나 삭제하세요.
6. 박스는 보이는 객체의 경계에 맞추고, 화면 밖의 가려진 모양을 추측해 넓히지 마세요.
7. 수정한 라벨을 저장하고 `review.csv`의 `review_status`에 `reviewed`,
   `reviewer`에 검수자, `notes`에 불확실한 사례를 기록하세요.

실제 돌인지 흙덩어리인지 영상만으로 확실하지 않으면 임의로 정답을 확정하지 말고
`needs_confirmation`으로 기록해 현장 담당자에게 확인해 주세요.
흙덩어리 클래스를 임의로 추가하면 현재 두 클래스 학습 설정과 달라집니다.

## 특히 확인할 항목

- 같은 돌 하나에 박스가 두 개 그려졌는지.
- 장갑·손가락·롤러·가드가 감자나 돌로 표시됐는지.
- 화면 위·아래 경계에 일부만 보이는 물체가 잘못 분류됐는지.
- 붙어 있는 감자 두 개가 하나로 합쳐지거나 하나가 빠졌는지.
- 흐릿한 객체의 박스가 지나치게 크거나 작은지.

미리보기는 `previews`에 있지만 실제 수정은 `data`의 원본 이미지와 JSON으로 해야 합니다.
자동 초안 생성에는 누락 검수를 돕기 위해 판정 점수 0.25를 사용했습니다.
NMS 비교의 고정 판정 점수 0.45와 다르며, 기존 실행 설정을 바꾼 것이 아닙니다.

`manifest.json`에는 원본 시간, 프레임 PTS, 선택 이유, 모델 해시와 초안 생성 조건이 있습니다.
`review.csv`의 선택 이유는 추출 목적이며 실제 정답 종류를 보장하지 않습니다.
JSON 기본 필드는 X-AnyLabeling v4.2.0 공식 스키마와 대조했습니다.
실제 데스크톱 앱에서 여는 동작은 이 환경에서 확인하지 않았습니다.

검수 완료 후 별도 승인·데이터 검증을 거쳐 학습에 사용할 수 있습니다.
기존 검증·시험 구간이나 ZIP 평가 자료는 이 묶음에 포함하지 않았습니다.
