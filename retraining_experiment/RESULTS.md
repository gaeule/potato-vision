# v2 실제 재학습 결과

## 결론

88장으로 새 감자·돌 모델을 학습하고 기존 40장 모델과 비교했다.
**감자 오탐이 크게 줄었지만 누락과 돌 관련 지표가 모두 개선된 것은 아니다.**
기존 모델은 교체하지 않고 새 모델과 결과를 별도 폴더에 보존했다.

외부 사진 166장에서 감자 오탐은 72건에서 23건으로 감소했다.
누락은 9건에서 10건으로 증가했다. 두 클래스 시험 12장에서는 감자 오탐이
6건에서 2건으로 줄었으나 돌 오탐 1건이 새로 생겼다.

## 자료와 실제 학습

| 분할 | 이미지 | 감자 정답 박스 | 돌 정답 박스 |
|---|---:|---:|---:|
| 학습 | 88 | 473 | 39 |
| 검증 | 11 | 60 | 8 |
| 시험 | 12 | 33 | 7 |
| 외부 평가 | 166 | 192 | 정답 없음 |

학습 입력은 기존 40장과 추가 검수 48장이다.
65·71초의 상단 미확인 조각이 있는 2장은 계속 학습에서 제외했다.
사용자가 시각 확인한 43~49초 물체와 같은 기존 44·46·48초 장면은 포함했다.
인간 전문가가 전체 박스와 실물 재질을 확정한 데이터는 아니다.

기존과 같은 COCO 사전학습 `yolo11s.pt`에서 시작했다. 이전 감자·돌 체크포인트에서
이어 학습하지 않았다. SGD, seed 42, 입력 640, batch 8, workers 0,
최대 60에폭, patience 15, RTX 5080, 고정 프레임워크 버전을 유지했다.
44에폭에 조기 종료됐고 학습 CSV의 경과 시간은 약 97.6초다.
구현·검증·영상 작업 시간은 이 학습 시간에 포함되지 않는다.

원본 데이터에 라벨 캐시가 생기지 않도록 학습 88장과 검증 11장만
`outputs/train/training_dataset`에 실제 복사했다. 시험·외부 자료는 학습기에 전달하지 않았다.
캐시는 이 전용 복사본의 `labels/train.cache`, `labels/val.cache`에 생성됐다.

## 모델 선택

운영 조건은 실행 전에 confidence 0.45, NMS IoU 0.5, 정답 매칭 IoU 0.5로 고정했다.
NMS 0.5는 이전 검증 전용 비교에서 정한 값이며 이번 시험 결과를 보고 조정하지 않았다.
기존 모델과 새 모델 모두 같은 조건을 사용했다.

native best(29에폭)와 last(44에폭)를 각각 새로 로드해 검증 11장만 비교했다.

macro F1 0.962465로 같아 사전 동점 규칙에 따라 native best를 선택했다.

## 전체 영상에서 본 결과

기존·새 모델 모두 동일한 0.45/0.5 조건으로 원본 전체를 처리했다.

- 새 모델 영상: `outputs/video/annotated.mp4`
- 기존 모델 동일 조건 영상: `outputs/video_baseline/annotated.mp4`
- 고정 장면 비교 사진: `review/video_comparison.jpg`
- 각 영상 폴더의 `diagnostics/`: 20·35·65·70·71·78·80·83·130·134초 원본·표시본·검출 기록
- 각 영상 폴더의 `counts.json`: 모든 프레임의 검출 박스·점수·시각·개수

직접 확인한 주요 차이:

- **35초:** 수정 정답 감자 10개 기준 기존은 8개 정탐·2개 누락,
  새 모델은 10개 정탐·누락 0개다. 다만 같은 가려진 감자/장갑 영역에 추가 박스 1개가 남았다.
  학습에 포함된 장면의 진단 결과이며 일반화 성능 지표가 아니다.
- **70초:** 같은 NMS 0.5에서 두 모델 모두 돌 박스 1개다.
  이전 NMS 0.7에서 보였던 중복 제거를 이번 재학습만의 효과로 보지 않는다.
- **78초:** 두 모델 모두 감자 11개를 검출한다.
- **80초:** 기존의 상단 배경 박스가 새 결과에서 사라져 감자 예측이 10개에서 9개로 줄었다.
- **65초:** 큰 흰 돌은 검출한다. 상단 미확정 조각의 정답 여부는 여전히 보류다.
- **71초:** 새 모델이 상단 미확정 조각을 감자로 예측하지만, 이 예측을 정답으로 확정하지 않았다.
- **83·130초:** 보이는 돌을 별도 stone으로 검출한다.
- **134초:** 기존의 잘린 돌→감자 예측은 사라졌지만 해당 작은 돌의 누락은 남았다.

두 MP4는 H.264, 오디오 없음, 1280×720, 2,224프레임, 147.875초다.
전체 출력 프레임을 다시 디코딩해 원본 PTS·time base·프레임 길이와 모두 일치함을 확인했다.
완성 MP4의 실제 화면도 확인했다. 하단 `ON SCREEN`은 프레임별 검출 개수이며
고유 감자 수나 통과 누적 수량이 아니다.

## 검증과 수정 이력

- 실제 학습·선택·비교·새 영상·기존 비교 영상 명령 모두 종료 코드 0으로 완료했다.
- 기존 모델의 val/test 결과는 앞선 NMS 0.5 실험을 정확히 재현했다.
- 선택·비교의 이미지/모델 관측 400건을 원본 라벨과 독립 IoU 계산으로 다시 대조했다.
- 기존 원본·모델·데이터·검수 자료 3,397개 파일의 SHA-256이 그대로였다.
- 첫 선택 시 CLI 기본값 오류로 보호된 학습 폴더 충돌이 발생했다.
  출력에 쓰기 전에 중단됐으며, Namespace 초기값을 수정하고 실패를 재현한 회귀 검사를 추가했다.
  학습 자체는 다시 실행하지 않았다.
- B-프레임 인코딩에서 duration 불일치를 CPU로 재현했다.
  B-프레임 해제와 원본 PTS별 packet duration 지정으로 고쳤으며,
  마지막 구간까지 포함한 실제 CPU 인코딩 회귀 검사와 두 전체 GPU 영상 검증을 통과했다.
- native 후보·선택 가중치 해시와 외부 평가 파일 구성·해시를 실행 전에 강제 확인한다.
- Ruff·format·CPU smoke는 통과했다. Basedpyright는 오류 0개,
  외부 라이브러리 타입 경고 21개로 종료 코드 1이며 깨끗한 통과라고 표시하지 않는다.
  경고를 억제하지 않았다. LSP 서버 대신 기존 타입 검사 CLI를 사용했다.
- 독립 코드 재검토에서 이전 차단 사항이 해소됐음을 확인했다.

상세 근거는 `review/protocol.json`, `review/baseline_reference.json`,
`review/verification.json`, `outputs/train/`, `outputs/selection/selection.json`,
`outputs/comparison/comparison.json`에 있다.

## 사용 범위

현재까지 감자 오탐 감소 효과는 확인했다. 돌 오탐·부분 가림·중복 박스가 남아 있어
현장 완성 모델이나 모든 촬영 조건에서의 성능 보증으로 취급하면 안 된다.
한 영상의 반복 관측 및 이미 본 평가 자료에 대한 탐색적 결과다.
흙 별도 클래스, 고유 개수 추적, 실제 mm 크기 측정은 이번 범위에 포함되지 않았다.
기존 모델은 그대로 두었으며 새 모델을 기존 경로에 덮어쓰지 않았다.
