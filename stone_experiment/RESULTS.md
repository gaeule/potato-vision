# 감자·돌 2종 모델 실험 결과

## 결론

기존 모델의 임계값 0.45 영상을 만들고, 돌 라벨을 추가한 2종 YOLO11s 모델도 학습·비교했습니다.
새 모델은 돌을 별도로 식별하지만, 모든 지표가 좋아진 것은 아닙니다.
기존 모델과 0.25 결과는 교체하지 않고 보존했습니다.

- 새 감자·돌 모델, 임계값 0.45: `outputs/new_video_conf045/annotated.mp4`

- 새 라벨: `annotations.json`
- 실행 방법: `README.md`

파란색은 감자, 청록색은 돌 예측입니다.
영상 하단 `ON SCREEN`은 현재 프레임의 예측 박스 수이며 고유 통과 수량이 아닙니다.

## 데이터와 조건

| 분할 | 이미지 | 감자 박스 | 돌 박스 |
|---|---:|---:|---:|
| 학습 0~84초 | 40 | 222 | 16 |
| 검증 92~112초 | 11 | 60 | 8 |
| 시험 120~146초 | 12 | 33 | 7 |

기존 감자 좌표 315개와 시간 분할을 그대로 유지하고, 돌 좌표 31개를 별도 버전에 추가했습니다.
이는 프레임별 관측 수이며, 서로 다른 돌 31개라는 뜻이 아닙니다.
한 촬영 장면의 소수 물체를 반복 관측한 자료입니다.
AI 시각 검수이며 실제 물질이 돌인지 확인한 인간 전문가 정답은 아닙니다.
특히 110/112초의 긴 회색 물체와 화면 경계의 작은 부분 가림은 추가 확인이 필요합니다.

새 모델은 기존 감자 모델에서 이어 학습하지 않고 원래 COCO 사전학습 YOLO11s에서 시작했습니다.
기존과 같은 seed 42, 640 입력, batch 8, SGD lr0=0.01,
최대 60에폭/patience 15 설정으로 RTX 5080에서 학습했습니다.
47에폭에 조기 종료됐습니다.

native best(32에폭)와 last(47에폭)를 검증 11장만으로 비교했습니다.
고정 confidence 0.45, NMS IoU 0.7, 정답 매칭 IoU 0.5에서 두 클래스 macro F1이
각각 0.9503과 0.9251이어서 32에폭 모델을 선택했습니다.
시험·ZIP 점수는 모델이나 임계값 선택에 사용하지 않았습니다.

## 동일 시험 구간 비교

두 모델 모두 같은 12장, 같은 새 정답 라벨, 같은 임계값 0.45를 사용했습니다.

| 지표 | 기존 감자 모델 | 새 감자·돌 모델 |
|---|---:|---:|
| 감자 정탐 | 33/33 | 33/33 |
| 감자 누락·다른 클래스 분류 | 0 | 0 |
| 감자 예측 오탐 | 4 | 6 |
| 돌을 `stone`으로 올바르게 식별 | 0/7 | 6/7 |
| 돌을 감자로 오분류 | 0 | 1 |
| 감자를 돌로 오분류 | 0 | 0 |
| 배경을 돌로 오탐 | 0 | 0 |

기존 모델은 돌 클래스가 없으므로 돌 7건을 모두 무시했습니다.
임계값을 0.45로 올린 기존 모델은 이 작은 시험 구간에서는 돌을 감자로 잡지 않았습니다.
따라서 새 모델이 돌→감자 오분류를 줄였다고 말할 수 없습니다.

새 모델은 돌 6건을 실제로 구분했지만 나머지 1건은 감자로 분류했습니다.
감자 오탐 6건의 구성은 배경 오탐 5건과 돌 오분류 1건입니다.
기존 감자 오탐 4건은 모두 배경 오탐입니다.

검증 구간에서도 감자 누락은 두 모델 모두 1건이지만,
감자 오탐은 기존 0건, 새 모델 3건이었습니다.
돌은 새 모델이 8건 중 7건을 식별하고 1건을 놓쳤습니다.

## 추가 ZIP 비교

ZIP 166장에는 감자 라벨만 있으므로 **감자 예측만 평가**했습니다.
이 결과로 돌 정밀도·재현율을 주장하지 않습니다.
해당 자료는 학습에 넣지 않았고, 이미 열람했던 자료에 대한 탐색적 평가입니다.

| 감자 지표 | 기존 모델 0.45 | 새 모델 0.45 |
|---|---:|---:|
| 정탐 | 184 | 183 |
| 오탐 | 102 | 72 |
| 누락 | 8 | 9 |
| 정밀도 | 64.34% | 71.76% |
| 재현율 | 95.83% | 95.31% |
| F1 | 0.7699 | 0.8188 |

오탐은 30개 줄었지만 감자 하나를 더 놓쳤습니다.
공급된 감자 라벨 자체의 누락·경계 오차도 이 집계에 영향을 줄 수 있습니다.

## 실제 장면에서 확인한 점

- **130초:** 기존 모델은 두 돌을 무시합니다. 새 모델은 두 돌을 각각
  `stone`으로 표시합니다. 두 모델 모두 화면 위쪽의 배경 오탐이 남았습니다.
- **134초:** 화면 맨 위에 일부만 남은 돌을 새 모델이 `potato 0.507`로 분류했습니다.
  정답 박스 `[415, 0, 448, 18]`, 예측과의 IoU 약 0.655입니다.
  이미 시험 결과를 본 뒤이므로 이 사례에 맞춰 임계값이나 정답을 바꾸지 않았습니다.
- **70초:** 화면 위쪽 돌 하나에 `stone` 박스가 두 개 생겼습니다.
  점수는 약 0.997과 0.534입니다. 시험 12장에 포함되지 않은 장면의 중복 검출로,
  작은 시험 표의 돌 오탐 0건이 전체 영상의 오탐 0건을 뜻하지 않음을 보여 줍니다.

상단 상태 표시가 작은 실패 박스를 가리지 않도록 최종 영상의 표시줄은 하단으로 옮겼습니다.
표시 위치만 바꾼 전후의 모든 프레임별 예측 수가 동일함을 확인했습니다.

## 실행·검증 근거

- 두 최종 영상 모두 H.264, 오디오 없음, 2,224프레임, 길이 147.875초입니다.
- 원본 전체 프레임과의 시간 오차는 0초입니다.
- 원본과 기존 실험 파일 1,485개의 SHA256이 모두 그대로입니다.
- 63장의 픽셀, 정규화 라벨, 분할 간격 8초, 데이터 해시를 독립 검사했습니다.
- 오분류·중복·누락·경계 IoU 집계는 독립적인 결정론적 300사례와 일치했습니다.
- CLI 기본 경로 오류를 수정하고 실제 데이터 준비 및 기본값 회귀 검사를 통과했습니다.
- 동시 실행 중 라이브러리 설정 파일 충돌을 발견해 프로세스별 폴더로 격리했습니다.
  두 별도 프로세스의 설정 JSON 로드와 독립 경로를 확인했습니다.
- 구문·Ruff·CPU 검증은 통과했습니다. Basedpyright는 오류 0개지만 엄격 경고 16개로
  종료 코드 1입니다. 경고를 숨기거나 타입 검사가 통과했다고 표시하지 않았습니다.
