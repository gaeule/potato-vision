# 감자 탐지 1차 실험 결과

## 결론

원본 영상만으로 직접 라벨을 작성하고 YOLO11s를 학습한 뒤, 별도로 받은 ZIP에서 평가했습니다.
감자는 잘 찾아내는 편이지만 돌·장갑 등을 감자로 판단하는 오탐이 남았습니다.
따라서 학습·추론이 가능한 첫 기준 모델이며, 현장 투입 가능한 완성 모델은 아닙니다.

## 먼저 열어볼 파일

- `inference/annotated.mp4`: 최종 모델의 원본 전체 추론 영상
- `runs/train/weights/selected.pt`: 실제 사용할 모델
- `review/final_video_samples.jpg`: 주요 장면 미리보기
- `review/train_labels_*.jpg`, `review/holdout_labels_*.jpg`: 작성한 라벨 검수 화면
- `evaluations/external/predictions/`: ZIP 166장에 대한 예측 이미지
- `README.md`: 환경과 재현 명령어

영상의 `ON SCREEN`은 한 프레임에서 탐지한 수입니다.
같은 감자가 여러 프레임에 반복 등장하므로 이 숫자를 합쳐 통과 수량으로 사용하면 안 됩니다.

## 데이터와 학습

| 구분 | 이미지 | 감자 박스 | 용도 |
|---|---:|---:|---|
| 원본 0~84초 | 40 | 222 | 학습 |
| 원본 92~112초 | 11 | 60 | 내부 검증·체크포인트 선택 |
| 원본 120~146초 | 12 | 33 | 내부 시험 |
| 추가 ZIP | 166 | 192 | 외부 탐색 평가, 학습 제외 |

원본의 AI 시각 라벨 총 315개를 작성하고 박스 오버레이를 확인했습니다.
현장 전문가 검수본은 아니며 부분 가림·모션 블러의 경계에 불확실성이 있습니다.
원본 MP4와 ZIP은 보존했습니다. 이미지·라벨 쌍과 원본 해시를 기록했습니다.

RTX 5080에서 YOLO11s, 640 입력, seed 42, batch 8, SGD로 학습했습니다.
최대 60에폭 설정에서 36에폭에 조기 종료됐습니다.

## 왜 selected.pt인가?

라이브러리의 `best.pt`는 검증 mAP50-95로 선택된 21에폭입니다.
AP가 높아도 실제 표시 임계값 0.25에서는 오탐이 매우 많았습니다.
따라서 `best.pt`와 `last.pt`를 **내부 검증 11장만** 사용해 비교했습니다.

| 체크포인트 | 검증 TP | 검증 FP | 검증 FN | 고정 임계값 F1 |
|---|---:|---:|---:|---:|
| native best, 21에폭 | 60 | 519 | 0 | 0.1878 |
| last, 36에폭 | 59 | 5 | 1 | 0.9516 |

conf=0.25, NMS IoU=0.7, 정답 매칭 IoU>=0.5입니다.
36에폭 모델을 `selected.pt`로 복사했습니다.
선택 로직은 `scripts/select_checkpoint.py`, 근거는 `selection/selection.json`입니다.
외부 점수는 선택 계산에 사용하지 않았습니다.

다만 이 운영점 선택 절차는 최초 탐색 평가에서 문제를 본 뒤 추가했습니다.
외부 자료를 이미 살펴본 실험이므로 완전히 미열람 상태의 최종 수락 시험으로 주장하지 않습니다.
최초 모델의 결과도 `evaluations_initial_ap/`, `inference_initial_ap/`에 보존했습니다.

## 실제 화면 표시 조건의 성능

아래 값은 conf=0.25에서 confidence 순서로 예측을 정답과 1:1 매칭한 결과입니다.
중복 박스와 빈 이미지의 오탐도 FP에 포함했습니다.

| 데이터 | TP | FP | FN | 정밀도 | 재현율 | F1 |
|---|---:|---:|---:|---:|---:|---:|
| 내부 검증 | 59 | 5 | 1 | 92.19% | 98.33% | 0.9516 |
| 내부 시험 | 33 | 10 | 0 | 76.74% | 100.00% | 0.8684 |
| 추가 ZIP | 184 | 150 | 8 | 55.09% | 95.83% | 0.6996 |

추가 ZIP 기준으로는 표시된 감자 박스의 약 55%만 정답과 일치했습니다.
높은 재현율만 보고 성능이 충분하다고 판단하면 안 됩니다.
영상 130초 부근에서는 실제 감자뿐 아니라 두 돌과 화면 위쪽 물체에도 박스가 생겼습니다.
ZIP 69초 예시에서도 감자 6개 외에 장갑 쪽 오탐이 보입니다.

### AP 지표

| 데이터 | mAP50 | mAP50-95 |
|---|---:|---:|
| 내부 검증 | 0.9936 | 0.7934 |
| 내부 시험 | 0.9950 | 0.8168 |
| 추가 ZIP | 0.9101 | 0.7058 |

AP는 여러 confidence 운영점에 걸친 지표입니다.
`metrics.json`의 라이브러리 precision/recall은 데이터별 best-F1 지점의 요약이며
화면 임계값 0.25의 값이 아닙니다. 운영 성능은 `fixed_confidence_metrics.json`을 확인하세요.

## 확인한 사항과 제한

- 전체 추론 영상: H.264, 오디오 없음, 원본과 같은 2,224프레임.
- 모든 프레임의 시간 오차: 0초. 끝 컨테이너 길이는 마지막 패킷 지속시간 때문에 약 0.025초 다릅니다.
- 가변 프레임률을 평균 FPS 시간 격자로 인코딩할 때 발생하던 DTS 중복을 수정했습니다.
- 63장 모두 재추출된 프레임과 픽셀이 일치하고, 학습/검증/시험 구간은 겹치지 않습니다.
- ZIP 166장의 이미지·JSON 짝, 192개 박스, 빈 라벨 87개를 확인했습니다.
- ZIP의 알려진 음수 x1 좌표 한 곳은 0으로 보정해 manifest에 기록했습니다.
- 선택 원본 63장과 ZIP 사이에 완전히 같은 RGB 이미지는 없었습니다.
  그러나 서로 다른 촬영일·물체임을 보장하지는 않습니다.
- 안전한 재생성, 부분 프레임 소유권 유지, 중복 예측 집계의 회귀 검증을 통과했습니다.
- Python 구문 검사와 Ruff는 통과했습니다.
  Basedpyright는 오류 0개지만 동적 JSON·CLI·ML API 등의 엄격 경고 146개로 종료 코드 1입니다.
  이 검사를 통과했다고 표시하거나 경고를 끄지는 않았습니다.

현재는 감자 단일 클래스입니다. 돌/흙 별도 식별, 실제 mm 크기, 객체 추적·고유 수량은 이번 결과에 포함하지 않습니다.
학습·시험 모두 매우 작은 자료이며 라벨의 불확실성이 있으므로 일반적인 현장 정확도로 해석할 수 없습니다.

## 다음 실험 제안

우선 돌·흙덩어리·장갑·설비가 나온 어려운 장면을 더 확보하고 라벨을 현장 담당자와 검수하는 것이 좋습니다.
그 후 감자/돌/흙덩어리 클래스로 확장하고, 새 촬영 세션을 최종 시험용으로 남겨두세요.
현재 ZIP 성능을 보고 반복적으로 맞추면 해당 ZIP은 더 이상 새로운 자료에 대한 평가가 아닙니다.
